
# Intehralnaja Pachvara

## Clicker Game для математиков/фанатов Б.П.Демидовича/любителей интегралов, написанная на C++ с использованием фреймворка Qt.

## 📸 Скриншоты


## ✨ Особенности

* 🔥 Интуитивно понятный геймплей с выбором сложности игры
* |**Ў**|    Игра полностью локализована на белорусский язык 
* 🎮 Простое управление
* 🖼️ Приятная графика
* 📊 Система HP и рейтинга по времени
* 🌍 Сохранение результатов

## 🛠️ Сборка и установка

### Требования

* **Qt** версии 6.8.2 или выше
* **Компилятор C++** с поддержкой C++17
* **CMake** 3.16+

### Клонирование репозитория
git clone https://github.com/Gerestal/Intehralnaja_pachvara.git

### Сборка с помощью CMake
mkdir build
cd build
cmake ..
cmake --build .

## 🎮 Управление

### В зависимости от выбранной сложности игры Вам будет необходимо кликнуть по интегралу определённое количество раз, чтобы оставить его без HP.
