
# Intehralnaja Pachvara

## Clicker Game для математиков/фанатов Б.П.Демидовича/любителей интегралов, написанная на C++ с использованием фреймворка Qt.

## 📸 Скриншоты


## ✨ Особенности

* 🔥 Интуитивно понятный геймплей с выбором сложности игры
*  Ў  Игра полностью локализована на белорусский язык 
* 🎮 Простое управление
* 🖼️ Приятная графика
* 📊 Система HP и рейтинга по времени
* 🌍 Сохранение результатов

## 🛠️ Сборка и установка

### Требования

* **Qt** версии 6.x или выше
* **Компилятор C++** с поддержкой C++17
*
